# 🍽️ Recipe App

A modern Android application designed for recipe management and discovery. This project utilizes the latest Android development standards, including **Jetpack Compose** for a declarative UI and **Kotlin DSL** for build configurations.

---

## 📱 Features

### 🔐 Secure Authentication
Integrated with Firebase Authentication to provide a seamless login and sign-up experience.  
- Supports email/password authentication  
- Ensures user data is protected across sessions  

### 🎲 Random Meal of the Day
Stuck on what to cook?  
- Generates a random recipe from the database or API  
- Provides high-quality images and full cooking details  

### 📂 Categorized Browsing
Discover recipes organized by categories:
- Seafood  
- Vegan  
- Desserts  
- Beef  

Smooth transitions allow users to explore cuisines easily.

### 🔍 Intelligent Search
- Search by dish name or ingredients  
- Real-time results optimized for speed  

### 📖 Comprehensive Recipe Details
Each recipe includes:
- **Ingredients List** – Clearly measured and formatted  
- **Step-by-Step Instructions** – Easy-to-follow cooking guide  
- **Visual Aids** – High-resolution images  

### ✨ Modern UI/UX
Built بالكامل باستخدام Jetpack Compose:
- Fluid animations  
- Material Design components  
- Responsive layouts
